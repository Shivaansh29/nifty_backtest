# M3: Engine, short straddle, costs and trade logging

## Demo

```bash
uv run nifty-backtest backtest                     # defaults: entry 3 sessions before expiry,
                                                   # 1 lot, Rs 20/order, 0.5 pt slippage per leg
uv run nifty-backtest backtest --slippage 1.0 --brokerage 0   # change the assumptions
uv run pytest -v                                   # 98 tests; 11 real-data tests skip without data/
```

Each run is saved to `runs/<run_id>/`:
- `config.json` and `manifest.json`;
- `trades.csv`, `marks.csv`, `equity.csv` and `skipped.csv`.

## What was built

| Where | What |
|---|---|
| `strategies/base.py` | The one interface every strategy implements: given the entry day's chain and the index close, return the legs |
| `strategies/short_straddle.py` | Sell 1 ATM call + 1 ATM put; ATM = nearest strike, ties go to the lower strike |
| `costs/model.py` | Dated rate lookup plus charges per sell order and per short leg at expiry; brokerage and slippage in `CostConfig` |
| `engine/backtest.py` | Calendar → entry → leg checks → fills → daily marks → settlement → costs → trade log and equity curve |
| `engine/runs.py` | Saves a run with config, git state, a data fingerprint and all logs |
| `marketdata/events.py` | Loads the sourced events and tags the trades whose window contains one |
| `reference/cost_rates.csv` | 19 dated rates, each citing an NSE circular, SEBI regulation, Finance Act or GST notification |
| `reference/events.csv` | 39 events: 32 RBI policy decisions, 6 Union Budgets, the 2024 election result |

  There are 0 stale and 0 missing daily marks, and the equity curve covers all 1,251 trading

## Key design decisions

1. **Every statutory rate comes from a primary document that I read.** The STT rows cite
   NSE's tax circulars, which implement each Finance Act and state who pays. There were
   **three** STT changes in the window, on 1 Apr 2023, 1 Oct 2024 and 1 Apr 2026. The spec
   listed only the last two.
2. **The conservative slab before Oct 2024.** NSE charged brokers by volume slab, from ₹53 down
   to ₹33 per lakh, so no single "client rate" existed. The table uses the highest incremental
   slab. From 1 Oct 2024 SEBI's true-to-label rule made it one flat rate.
3. **Who pays what at expiry.** A short option settled at expiry pays no brokerage (no order is
   placed) and no STT, which the purchaser pays. If it finishes in the money it is assigned,
   and SEBI's fee also applies to the notional value of assigned contracts (SEBI fee
   regulations, Explanation B). "Notional" is taken as settlement level × quantity, a stated
   assumption.
4. **Brokerage and slippage are assumptions, so they are configurable and recorded:**
   - ₹20 per executed order;
   - each sell fills 0.5 index points per unit below the official close.

   Every run saves the values it used. M7 will test how results move with them.
5. **A stale price is never a fill.** If either ATM leg had zero volume at entry, is missing, or
   has no known lot size, the week is skipped with the reason logged. None were skipped.
6. **The equity curve is marked at every close.**
   - It equals capital + realised P&L of finished trades + the open trade's net
     mark-to-market (at the close, after fills and charges).
   - A missing mark would leave that day empty, never filled in.
   - Re-dated contracts are followed through their label change.
7. **P&L in three units.** Every trade logs ₹ (actual lot size), index points per unit, and %
   of premium. Both gross and net versions are kept, so M4 can show results with and without
   costs.
8. **Event tagging uses a strict window, entry close to expiry.** An RBI or Budget announcement
   on the entry day happened before the entry close, so it is already in the entry prices and
   is not counted.
9. **Runs are reproducible.** Each run records the git commit (and whether the working tree was
   dirty), the date range, the trading-day count, one SHA-256 over every stored day's Parquet
   file, and hashes of the index data and every reference CSV.

## Explain-back questions

1. On 3 Jun 2024 the straddle collected 669.10 points and paid out 428.60 at expiry. Walk
   through where each number comes from in NSE's raw files. Why is the CE worth zero even
   though its last traded price that day was 29.35?
2. Why does a short leg that expires in the money cost a little more than one that expires
   worthless, even though no order is placed?
3. Before October 2024 NSE's transaction charge depended on the broker's monthly volume. What
   rate does the backtest use, and why is that the conservative choice?
4. What does the engine do if the ATM call had zero volume on the entry day, and why not just
   use its close?
5. Brokerage is the largest cost line in this run. Which assumption is that, where is it set,
   and how would you show a reviewer what happens if it changes?
